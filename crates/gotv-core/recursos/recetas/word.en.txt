Microsoft Word (tested 2026-11-11). Word starts WITHOUT a document: create it, don't look for windows.
Each block is sent as ["applescript", "<the block>"], with plain quotes (no backslashes \).

NEW WITH TEXT (\n inside the quotes = line break):
tell application "Microsoft Word"
activate
make new document
set content of text object of active document to "Title\n\nFirst paragraph.\n\nSecond paragraph."
end tell

APPEND AT THE END:
tell application "Microsoft Word" to insert text "\nAnother paragraph." at end of text object of active document

READ THE TEXT:
tell application "Microsoft Word" to get content of text object of active document

SAVE (.docx or .pdf; inside the project, «letter.pdf» is fine) — NEVER with your own `save as` (Word lives in a sandbox):
["guardar", "Microsoft Word", "letter.docx"]
["guardar", "Microsoft Word", "letter.pdf"]

OPEN a .docx: ["abrir", "Microsoft Word", "/ABSOLUTE/path/doc.docx"]
CLOSE without saving: tell application "Microsoft Word" to close active document saving no
