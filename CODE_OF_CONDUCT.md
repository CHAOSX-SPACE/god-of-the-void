# Code of conduct

The rule is short: **contempt is for imperfection, never for the person who
brought it.**

## Expected

- Say what is wrong, where, and how you measured it.
- Bring the number, the command, or the reproduction. Assertions without
  evidence get judged like any other claim.
- Disagree hard about the work. Design arguments are welcome and get settled by
  measuring, not by seniority.

## Not accepted

- Personal attacks, harassment, or making someone's identity part of a
  technical argument.
- Pretending a result you did not measure. A wrong number offered honestly is
  a mistake; a number invented to win an argument is not.

## Enforcement

Report to the repository owner through a
[security advisory](https://github.com/CHAOSX-SPACE/god-of-the-void/security/advisories/new)
or a direct issue if it does not need privacy. Maintainers may edit, hide or
reject contributions that break this, and will say why.
