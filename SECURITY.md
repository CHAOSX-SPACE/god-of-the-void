# Security

*Español abajo.*

GOTV runs an AI agent that reads, writes and executes on your Mac, so its
defences matter: the permission engine, the macOS sandbox (Seatbelt) around
every command, the network proxy, the keychain that holds your keys, and the
remote and mobile channels.

## Reporting a vulnerability

Please **do not open a public issue**. Use GitHub's private report:
**Security → Report a vulnerability** on
[github.com/CHAOSX-SPACE/god-of-the-void](https://github.com/CHAOSX-SPACE/god-of-the-void/security).

Include the GOTV version, what an attacker can do, and the steps to reproduce
it. You will get an answer, and credit in the release notes if you want it.

## Supported versions

Only the latest release receives fixes while GOTV is in 0.x.

## Seguridad (español)

GOTV corre un agente de IA que lee, escribe y ejecuta en tu Mac. Si encuentras
una falla de seguridad, **no abras un issue público**: usa el reporte privado de
GitHub (**Security → Report a vulnerability**) con la versión, qué puede hacer
un atacante y cómo reproducirlo. Mientras GOTV esté en 0.x, sólo la última
versión recibe arreglos.
